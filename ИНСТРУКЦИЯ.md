# 🤖 Telegram Бот-Нутрициолог - Инструкция по запуску

## 📋 Что нужно сделать

### 1️⃣ Получить токены

#### Telegram Bot Token

1. Открой Telegram
2. Найди [@BotFather](https://t.me/BotFather)
3. Отправь команду: `/newbot`
4. Придумай название бота (например: "Мой Нутрициолог")
5. Придумай username бота (должен заканчиваться на `bot`, например: `my_nutrition_bot`)
6. **Скопируй полученный токен** - он выглядит примерно так:
   ```
   1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   ```

#### OpenAI API Key

1. Зарегистрируйся на [OpenAI](https://platform.openai.com/)
2. Перейди в [API Keys](https://platform.openai.com/api-keys)
3. Нажми "Create new secret key"
4. Дай ключу название (например: "Nutrition Bot")
5. **Скопируй ключ** - он выглядит так:
   ```
   sk-proj-xxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
6. ⚠️ **ВАЖНО**: Пополни баланс на $5-10 в [Billing](https://platform.openai.com/settings/organization/billing/overview)

### 2️⃣ Настроить файл .env

1. Открой файл `.env` в корне проекта
2. Вставь свои токены:

```env
TELEGRAM_BOT_TOKEN=твой_токен_от_BotFather
OPENAI_API_KEY=твой_ключ_от_OpenAI
DATABASE_PATH=./data/nutrition.db
```

**Пример заполненного файла:**
```env
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxxxxxxxxxxxxxxxxxx
DATABASE_PATH=./data/nutrition.db
```

### 3️⃣ Запустить бота

Открой командную строку в папке проекта и выполни:

```bash
npm start
```

Должно появиться:
```
✅ База данных инициализирована
🤖 Бот запущен успешно!
```

### 4️⃣ Протестировать

1. Открой Telegram
2. Найди своего бота по username
3. Нажми START или отправь `/start`
4. Следуй инструкциям бота!

## ❓ Частые проблемы

### Ошибка: "401 Unauthorized" от Telegram
➡️ Неправильный токен бота. Проверь `.env` файл.

### Ошибка: "401 Incorrect API key" от OpenAI
➡️ Неправильный API ключ. Проверь `.env` файл.

### Ошибка: "Insufficient quota" от OpenAI
➡️ Закончились деньги на балансе OpenAI. Пополни счет.

### Бот не отвечает на сообщения
➡️ Убедись, что бот запущен (npm start) и в консоли нет ошибок.

### База данных не создается
➡️ Папка `data/` создастся автоматически при первом запуске.
