## 1. 👤 ВЫ: создать бота в Telegram (≈5 минут)

1. Откройте Telegram, найдите **@BotFather**, нажмите `/start`.
2. Отправьте `/newbot`, укажите имя (например «Диетолог-ассистент») и username, оканчивающийся на `bot` (например `my_nutrition_ai_bot`).
3. BotFather пришлёт **токен** вида `123456789:AAH...`. Сохраните его и **никому не показывайте** — это пароль от бота.

---

## 2. 👤 ВЫ: получить ключ OpenAI (для фото, голоса, анализов и консультаций)

Без ключа бот работает, но без ИИ: блюда вводятся вручную, фото/голос/консультации/анализы отключены.

1. Зарегистрируйтесь на https://platform.openai.com и пополните баланс (оплата за фактическое использование).
2. Создайте ключ в разделе API keys. Он начинается с `sk-`. Сохраните его.
3. Модель по умолчанию — `gpt-4o-mini` (умеет смотреть фото, дешёвая). Для голоса — `whisper-1`. Менять можно переменными `OPENAI_MODEL` и `WHISPER_MODEL`.

> ⚠️ **Риск, который нужно проверить до запуска:** OpenAI не предоставляет API всем регионам. Серверы Amvera находятся в России,
> и запросы к OpenAI с российского сервера могут блокироваться. Проверьте после деплоя: если в логах будет
> `Connection error` или `403 / unsupported_country`, ИИ-функции не заработают. Тогда нужен другой провайдер (например, Yandex GPT или GigaChat)
> или прокси. Скажите мне, и я переведу `bot/ai.py` на нужный сервис. Остальной бот от этого не зависит.

## 3. Запуск на своём компьютере (по желанию, для проверки)

Нужен Python 3.11+.

```bash
cd nutrition-telegram-bot
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
export BOT_TOKEN="123456789:AAH..."
export OPENAI_API_KEY="sk-..."     # можно не задавать
python main.py
```

Откройте бота в Telegram и нажмите `/start`. Остановить — `Ctrl+C`.

## 4. 👤 ВЫ + я: деплой на Amvera

**Что я могу, а что нет.** Я не могу зайти в ваш аккаунт Amvera и нажимать кнопки в панели:
у меня в песочнице нет доступа к сайту Amvera, только к GitHub, PyPI и npm. Поэтому часть действий делаете вы (шаги ниже, около 10 минут).
Всё, что касается кода и конфига, я уже подготовил: в репозитории лежит `amvera.yml`, `requirements.txt` и `main.py`.

### 4.1. Код в GitHub

Код сохраняется в ветке `arena/139e9b22-nutrition-telegram-bot`. Для деплоя его нужно положить в ветку, которую
Amvera будет собирать (обычно `main`). Слияние в `main` сделаем вместе, когда вы подтвердите, что всё работает.

### 4.2. 👤 ВЫ: создать приложение в Amvera

1. Войдите в личный кабинет Amvera, создайте проект (тип «Приложение» / «Application»).
2. Способ загрузки: подключите GitHub-репозиторий `nilofaleksey-rgb/nutrition-telegram-bot`
   или загрузите код через Git-remote, который Amvera покажет в настройках.
3. Amvera прочитает `amvera.yml`: Python 3.11, установка из `requirements.txt`, запуск `main.py`.
   Папка `/data` подключается автоматически (`persistenceMount: /data`).

### 4.3. 👤 ВЫ: задать переменные окружения в Amvera

В настройках приложения найдите раздел переменных окружения (в интерфейсе Amvera он может называться по-другому) и добавьте:

| Имя | Значение | Обязательно |
|---|---|---|
| `BOT_TOKEN` | токен от BotFather | да |
| `OPENAI_API_KEY` | ключ `sk-...` | нет (без него ИИ отключён) |
| `DB_PATH` | `/data/bot.db` | да (иначе база сотрётся при каждом деплое) |
| `TIMEZONE` | `Europe/Moscow` | нет, по умолчанию так же |

Переменные с ключами не коммитьте в GitHub. `.env` уже в `.gitignore`.

### 4.4. Запуск и проверка

1. Запустите деплой (кнопка Deploy или «Развернуть» — название может отличаться) и дождитесь сборки.
2. Откройте **Логи**. Должна появиться строка `Бот запущен, начинаю polling…`.
   Если там `BOT_TOKEN` — перепроверьте переменную. Если `Connection error` к OpenAI — см. раздел 2.
3. Напишите боту `/start` и пройдите онбординг, добавьте блюдо, откройте дневник.

## 5. Как пользоваться (для заказчика)

- **🥒 Дневник** — блюда за сегодня, ✏️ править, 🗑 удалить, ◀️ ▶️ листать дни, ➕ добавить за дату.
- **➕ Добавить блюдо** — текст, голос или фото. Выберите приём пищи (завтрак, обед, ужин, перекус).
- **⚖️ Вес** — замер веса, сравнение с прошлым, график.
- **📊 Отчёты** — приёмы пищи за день, неделя, итоги с начала.
- **🍽 Что на ужин** — подбор под остаток калорий и БЖУ.
- **🧪 Анализы** — фото анализов, сравнение с прошлым анализом, рекомендации.
- **💬 Консультация** — любой вопрос по питанию. Фраза «дай более развернутый ответ» включает подробный режим, «коротко» — короткий.
- **👤 Профиль** — данные, норма, пересчёт.

## 6. Что ещё стоит знать

- **Точность фото.** ИИ оценивает порцию по картинке, это примерно (±20–30%). Точнее — когда вы пишете граммы и ккал вручную.
- **Резервная копия базы.** Данные лежат в `/data/bot.db` на Amvera. Раз в неделю или месяц можно скачивать файл через панель, если она это позволяет. Иначе попросите меня добавить выгрузку в Telegram.
- **Норма калорий — ориентир.** Формула Миффлина–Сан Жеора и коэффициенты активности дают приблизительный результат. Для клиентов с заболеваниями нужен врач.
- **Что не сделано (следующий этап):** утренняя автоматическая сводка по расписанию, учёт витаминов по блюдам, напоминания о замере веса, выгрузка базы в Telegram.
