# Инструкция: бот, нейросеть GigaChat и деплой на Amvera

Что я сделал сам, а что нужно от вас, отмечено метками:
**👤 ВЫ** — действие в ваших аккаунтах (Telegram, Сбер, Amvera), доступа к ним у меня нет.
**🤖 Я** — то, что я сделаю в репозитории, когда вы дадите доступ.

---

## 1. Telegram-бот (токен)

1. **👤 ВЫ:** в Telegram откройте @BotFather → `/newbot` → имя и username, оканчивающийся на `bot`.
2. Получите токен вида `123456789:AAH...`.
3. **Не присылайте токен в чат, если можно обойтись.** Его лучше вставить сразу в Amvera (раздел 4).
   Если уже отправили — зайдите в @BotFather, `/mybots` → бот → **API Token** → **Revoke current token**, и используйте новый.

---

## 2. Нейросеть: GigaChat (Сбер), бесплатно

Выбрал GigaChat, потому что это единственный из проверенных вариантов, который работает из России без VPN. Gemini официально не работает из России (OpenAI, по моим данным, тоже), поэтому
варианты с ними рискованны, а сервисы «без VPN» с обещаниями бесплатного доступа — перепродавцы, на которые я не стал бы опираться.

По документации Сбера (тарифы для физлиц, обновление 2026): бесплатно даётся квота токенов на 12 месяцев, разделённая по моделям.
Один поток запросов одновременно. Условия и модели могут меняться, поэтому сверяйтесь с кабинетом.

**Шаги:**

1. **👤 ВЫ:** зайдите на https://developers.sber.ru и войдите по **СберID** (нужна российская SIM-карта).
2. **👤 ВЫ:** создайте проект GigaChat API для физлиц, scope — `GIGACHAT_API_PERS`.
3. **👤 ВЫ:** скопируйте **«Авторизационные данные»** (строка base64). Это и есть `GIGACHAT_AUTH_KEY`. Не публикуйте её.
4. **👤 ВЫ:** в кабинете проверьте, какие модели доступны вашему аккаунту. Для фото нужна модель, которая понимает изображения
   (в примере `GigaChat-2-Max`, но это надо подтвердить). Если её нет, сообщите мне, и я поменяю `GIGACHAT_VISION_MODEL`.
5. **👤 ВЫ + 🤖 Я:** сертификат Минцифры. Запросы к GigaChat идут через российский корневой сертификат. Его нужно скачать
   с сайта Сбера (раздел «сертификаты НУЦ Минцифры», файл `.pem`) и положить в `certs/russian_trusted_root_ca.pem`.
   Я не могу скачать его из песочницы (сайт Минцифры недоступен), поэтому файл кладёте вы, а я коммичу.
   Временный обход на время отладки: `GIGACHAT_VERIFY_SSL=false`. Так работать можно, но небезопасно: не оставляйте это надолго.

**Что уже реализовано в коде** (`bot/llm.py`, класс `GigaChatBackend`):
- получение OAuth-токена по `GIGACHAT_AUTH_KEY` и его обновление (токен живёт 30 минут);
- текстовые запросы: консультации, советы, подбор ужина, рекомендации по анализам;
- фото: загрузка в `/files` и отправка с сообщением (для фото блюд и скриншотов анализов);
- повтор запроса при истёкшем токене и при ошибке «слишком много запросов»;
- все запросы идут строго по одному, как требует лимит физлица.

**Чего пока нет:** голосовой ввод. GigaChat речь не распознаёт, для неё нужен отдельный сервис Сбера (SaluteSpeech).
Голос в боте сейчас честно отвечает «пока не подключён». Если нужен — подключу SaluteSpeech отдельным шагом.

**Запасной вариант — OpenAI.** Если GigaChat не задан, а `OPENAI_API_KEY` задан, бот использует OpenAI (с голосом через Whisper).
Из России этот вариант может не работать.

## 3. Запуск на своём компьютере (для проверки)

Нужен Python 3.11+.

```bash
cd nutrition-telegram-bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN="123456789:AAH..."
export GIGACHAT_AUTH_KEY="..."        # необязательно: без него ИИ отключён
python main.py
```

Тесты: `python -m unittest discover -s tests -t .`

## 4. Деплой на Amvera

**Что я могу, а что нет.** Из моей песочницы доступны только GitHub, PyPI и npm. Сайт Amvera и его git-сервер (`git.amvera.ru`)
недоступны, поэтому подключиться к вашему аккаунту и пушить на Amvera я не могу. Это ограничение среды, не решение.
Зато я подготовил всё, что нужно для сборки: `amvera.yml`, `requirements.txt`, `main.py`.

**Способ 1 — через Git (как в вашем прошлом проекте).**

1. **👤 ВЫ:** в панели Amvera создайте проект типа «Приложение» (Python). В нём будет адрес git-репозитория проекта — скопируйте его.
2. **👤 ВЫ:** в настройках Amvera добавьте переменные окружения (раздел 4.1). Имена такие же, как в `.env.example`.
3. **👤 ВЫ + 🤖 Я:** код должен оказаться в ветке, которую Amvera собирает (обычно `master`). Команда на вашем компьютере:
   ```bash
   git remote add amvera <адрес из панели Amvera>
   git push amvera arena/139e9b22-nutrition-telegram-bot:master
   ```
   Логин и пароль (или токен доступа) Git запросит у вас. **Их не нужно присылать мне в чат.**
4. Amvera соберёт образ (Python 3.11, `requirements.txt`) и запустит `main.py`. Папка `/data` подключается автоматически.

**Способ 2 — без Git вручную.** Если в панели Amvera есть подключение GitHub-репозитория, выберите его и ветку.

### 4.1. Переменные окружения в Amvera

| Имя | Значение | Обязательно |
|---|---|---|
| `BOT_TOKEN` | токен от BotFather | да |
| `DB_PATH` | `/data/bot.db` | да (иначе база сотрётся при каждом деплое) |
| `TIMEZONE` | `Europe/Moscow` | нет |
| `GIGACHAT_AUTH_KEY` | «Авторизационные данные» из Сбера | для ИИ |
| `GIGACHAT_VISION_MODEL` | модель с поддержкой фото (проверить в кабинете) | для фото |
| `GIGACHAT_VERIFY_SSL` | `true` (временно `false`, если нет сертификата) | нет |

Сертификат `certs/russian_trusted_root_ca.pem` кладётся в репозиторий, поэтому его в переменные не добавляют.

### 4.2. Проверка

1. В логах Amvera должна появиться строка `ИИ: GigaChat ...` и `Бот запущен, начинаю polling…`.
2. Если ошибка `SSL` — проверьте сертификат (шаг 2.5). Если `401` от GigaChat — проверьте `GIGACHAT_AUTH_KEY`.
3. Напишите боту `/start`, пройдите настройку, добавьте блюдо, откройте дневник, попробуйте «💬 Консультация».

## 5. Что сохраняется и где

- Дневник, профили, вес и анализы лежат в SQLite-файле `/data/bot.db` на Amvera. Раз в какое-то время выгружайте его
  (через панель Amvera, если она позволяет скачать файлы, либо попросите меня добавить команду выгрузки в Telegram).
- Токены и ключи храните только в переменных Amvera. В GitHub их не коммитим (`.env` в `.gitignore`).
