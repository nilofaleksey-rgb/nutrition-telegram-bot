# ЧТО НУЖНО СДЕЛАТЬ ТЕБЕ

## 1. Получить Telegram Bot Token

1. Открой Telegram на телефоне/компьютере
2. Найди бота **@BotFather** (это официальный бот Telegram)
3. Отправь команду: `/newbot`
4. Придумай название (например: "Мой Диетолог")
5. Придумай username (должен быть на английском и заканчиваться на `bot`, например: `my_diet_helper_bot`)
6. **СКОПИРУЙ ТОКЕН** который он даст - выглядит примерно так:
   ```
   6789012345:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
   ```

## 2. Получить OpenAI API Key

1. Зайди на https://platform.openai.com/
2. Зарегистрируйся (нужна почта и телефон)
3. Перейди сюда: https://platform.openai.com/api-keys
4. Нажми **"Create new secret key"**
5. Дай имя ключу (например: "Nutrition Bot")
6. **СКОПИРУЙ КЛЮЧ** - выглядит так:
   ```
   sk-proj-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
7. ⚠️ **ВАЖНО**: Зайди в Billing (https://platform.openai.com/settings/organization/billing/overview) и пополни баланс на $5-10

## 3. Вставить токены в файл .env

Открой файл `.env` в папке проекта и вставь туда свои токены:

```env
TELEGRAM_BOT_TOKEN=сюда_вставь_токен_от_BotFather
OPENAI_API_KEY=сюда_вставь_ключ_от_OpenAI
DATABASE_PATH=./data/nutrition.db
```

**Пример:**
```env
TELEGRAM_BOT_TOKEN=6789012345:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
DATABASE_PATH=./data/nutrition.db
```

## 4. Запустить бота

Открой командную строку (cmd) в этой папке и выполни:

```bash
npm start
```

Если всё правильно, увидишь:
```
✅ База данных инициализирована
🤖 Бот запущен успешно!
```

## 5. Протестировать в Telegram

1. Открой Telegram
2. Найди своего бота по username (который создал в BotFather)
3. Нажми **START**
4. Готово! Бот работает!

---

## Если что-то не работает

### "401 Unauthorized"
→ Неправильный токен Telegram. Проверь `.env`

### "401 Incorrect API key"
→ Неправильный ключ OpenAI. Проверь `.env`

### "Insufficient quota"
→ Закончились деньги на OpenAI. Пополни баланс

### Бот не отвечает
→ Убедись что `npm start` запущен и нет ошибок в консоли
